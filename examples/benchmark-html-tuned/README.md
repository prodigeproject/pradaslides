# PradaSlides tuned HTML benchmark

This candidate is the controlled visual-tuning counterpart to `examples/benchmark-html/`.

The comparison locks the same seven-slide order, audience-facing copy, image sources, 1600 × 900 stage, and presenter runtime. Only the design decisions change. The canonical brief is in `brief-prompt.txt`.

The original historical prompt was not preserved, so this is a retrospective content-locked comparison rather than a claim that the original generation prompt was recovered.
