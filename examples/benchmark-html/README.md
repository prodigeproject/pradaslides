# PradaSlides public HTML benchmark

This is a deliberately fictional, public-safe benchmark deck for the HTML presenter. It demonstrates the end-to-end PradaSlides method rather than a single visual style:

- a decision-led brief and narrative arc;
- topology changes between slides instead of one repeated card layout;
- deliberate image roles and protected crops;
- large, stage-readable typography with checked text/background contrast;
- capability-aware production routes; and
- a presenter console that can be used for review, navigation, notes, and print/PDF output.

Run it from the repository root with a local server, then open:

```text
http://127.0.0.1:8765/examples/benchmark-html/
```

The deck uses remote Unsplash images so the repository does not redistribute third-party image files. The photos are illustrative only; they are not evidence for any real client, result, or case study.
